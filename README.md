# Examinerande gruppuppgift – Grupp 3

## Sammanfattning

Vi har genomfört analyser av flera centrala nyckeltal i datasetet, bland annat försäljning per produktkategori och stad samt genomsnittligt ordervärde (AOV).

Utifrån resultaten har vi även identifierat områden för vidare undersökning. Det handlar bland annat om att analysera geografiska skillnader i försäljningen, undersöka orsakerna till nedgången i försäljningen under mars 2024 samt utvärdera möjligheterna att prioritera och vidareutveckla de produktkategorier som står för den största försäljningen.

## Installation och utvecklingsmiljö

Vi har använt Python 3.11.7 och skapat en virtuell miljö (`.venv`) för att hålla projektets bibliotek och beroenden separerade från datorns övriga Python-installationer.

Efter att ha skapat och aktiverat miljön installerade vi samtliga nödvändiga bibliotek med hjälp av `requirements.txt`. Filen innehåller de bibliotek och versioner som projektet använder, vilket gör att alla gruppmedlemmar kan arbeta med samma förutsättningar.

Detta ger en gemensam och konsekvent utvecklingsmiljö och minskar risken för problem som kan uppstå när olika biblioteksversioner används.
